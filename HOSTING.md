# Hosting on Render (free)
1. Push this folder to a GitHub repo (.env.local is gitignored — never commit it).
2. Render Dashboard → New → Blueprint → pick the repo (uses render.yaml).
3. When prompted, set GEMINI_API_KEY (secret). Deploy.
4. On your phone, open the https://the-other-writer.onrender.com URL → browser menu → Add to Home Screen.
Note: free services sleep after ~15 min idle; first load after that takes ~1 min.
